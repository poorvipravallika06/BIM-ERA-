 DAY - 1 

 
This Python practice repository is a comprehensive Day 1 learning module designed to build a strong foundation in conditional programming and logical decision-making. It includes 30 practical programs that demonstrate the use of essential comparison and logical operators such as >, <, >=, <=, ==, !=, along with logical connectors like and, or, and not. Each program solves real-world scenarios including employee eligibility verification, student pass/fail analysis, login authentication, attendance validation, driving eligibility, project deadlines, salary requirements, safe temperature checks, and category or role validation. Through these exercises, learners gain hands-on experience in implementing if-else statements, combining multiple conditions, validating user input, and creating logic-based solutions. This project serves as a beginner-friendly guide to understanding how decision-making structures are used in everyday software applications, security systems, educational tools, and management systems

DAY - 2 


Foundational programming skills by focusing on more complex real-world problem-solving using conditional statements, nested decision-making, and logical operators. The module consists of 20 practical programs covering advanced scenarios such as employee promotion eligibility, scholarship approval, secure login systems, flight boarding verification, bank loan approval, smart home security, gym membership categorization, weather alert systems, and online shopping discounts. Through these exercises, learners extensively apply essential operators including comparison operators (>, <, >=, <=, ==, !=), arithmetic operators (+), and logical operators (and, or) while mastering control structures like if, elif, and else. The programs emphasize decision-based application development, user authentication, classification systems, and automation logic, helping beginners understand how Python is used in management systems, security applications, educational analysis, e-commerce, and real-world software workflows. Overall, this project strengthens programming logic, enhances analytical thinking, and builds a solid base for developing more advanced Python applications.
